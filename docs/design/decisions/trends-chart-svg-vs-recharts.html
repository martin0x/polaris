Trends chart comparison

The same six months of sample data, rendered both ways. Hover the bars in each — the tooltip behavior is part of the comparison.

Decision — resolved June 2026

Recharts (Option B) shipped. The live chart is src/systems/expenses/components/TrendsChart.tsx, backed by the recharts dependency in package.json.

Free tooltips, legend, and responsiveness plus a trivial path to line/area charts later outweighed the ~150 kB dependency and the leftover library chrome (animation curve, tooltip, legend layout) that doesn't fully match Polaris tokens. This page is kept as the record of that trade-off — re-open it if bundle size or theming fidelity later makes the custom SVG (Option A) worth the ~100 lines we'd own.

Option A — custom SVG

~100 lines we own, styled directly with tokens, no dependency.

This is what would ship: grouped monthly bars, mono axis labels, paper-card tooltip. Anything beyond this (lines, brushing, zoom) we would build ourselves.

Option B — Recharts

Library defaults re-themed toward Polaris as far as its API allows.

Adds a ~150 kB dependency. Tooltips, legends, and responsiveness come free, and growing into line/area charts later is trivial. Look closely at the leftover library styling — animation curve, tooltip chrome, legend layout.
